# Élan Coaching

Site vitrine statique, composé de quatre pages : accueil, à propos, programmes et contact.

## Ouvrir dans VS Code

1. Ouvrez le dossier `coaching-website` dans VS Code.
2. Ouvrez `index.html` dans votre navigateur, ou utilisez l'extension **Live Server** pour un aperçu avec actualisation automatique.

## Personnaliser rapidement

- Remplacez le nom **Élan** et les textes directement dans les fichiers `.html`.
- Les couleurs et la police sont regroupées en haut de `styles.css`.
- L'adresse de contact se trouve dans `contact.html`.
- Le formulaire est visuel : branchez-le à Formspree, votre CRM ou votre service e-mail avant de publier le site.
